# Engineering

Skills for implementation, review, diagnosis, testing, architecture, tooling, and framework guidance.

- `autoreview`: runs a structured pre-commit or pre-ship review.
- `code-review`: reviews changes against repository standards and originating specs.
- `diagnosing-bugs`: follows a disciplined diagnosis loop for hard bugs and regressions.
- `domain-modeling`: sharpens domain language, context, and architecture decisions.
- `github-deep-review`: performs evidence-first review of GitHub bugs and pull requests.
- `gsap-core`: covers core GSAP tweens, easing, defaults, and responsive animation.
- `gsap-frameworks`: integrates GSAP with Vue, Svelte, and other non-React frameworks.
- `gsap-performance`: improves GSAP animation smoothness and runtime efficiency.
- `gsap-plugins`: covers GSAP plugin registration and use.
- `gsap-react`: integrates GSAP with React and Next.js lifecycles.
- `gsap-scrolltrigger`: builds scroll-linked animation, pinning, and scrub effects.
- `gsap-timeline`: sequences animation with GSAP timelines.
- `gsap-utils`: applies GSAP mapping, interpolation, snapping, and collection utilities.
- `implement`: implements work from a spec or ticket set.
- `oracle`: bundles repository context for a second-model review.
- `shadcn`: manages shadcn components, registries, styling, and composition.
- `skill-cleaner`: audits skill prompt budget, usage, and duplication.
- `tdd`: red-green-refactor workflow with tracer-bullet slices.
- `thermo-nuclear-code-quality-review`: extremely strict maintainability review for abstraction quality, giant files, and spaghetti-condition growth.
